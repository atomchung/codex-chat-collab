# Review Loop Log

公開的、去識別化的紀錄庫，用來整理 Codex 主導的實作與獨立 reviewer 審查流程中發現的問題、修正方式和後續驗證。

## 記錄原則

- 遇到 review 流程、finding 品質、修正驗證、合併後驗收或重複問題時，開一筆 issue；相似問題連到既有 issue。
- 把觀察到的事實、推測的原因、採取的修正和驗證結果分開寫。沒有證據的根因標成假設。
- 問題修正後補上結果與驗證狀態；未解決的問題保留為 open。
- 記錄的是可重用的流程經驗，不是個別公司的投資或產品資料。

## 公開資料安全

這個 repository 是公開的。建立 issue 前先移除或概括：持倉與交易、未公開論點或策略、帳戶與個人資料、私有 repository/PR/branch/commit 連結、存取憑證、內部檔案路徑、未授權的截圖及任何客戶機密。

只留下理解和修復流程問題所需的最少、已去識別化資訊。若無法安全公開，先記錄為「需私下處理」，不要貼入公開 issue。

## Issue 格式

請使用 [Review Process Issue 表單](https://github.com/atomchung/review-loop-log/issues/new/choose)。不要直接附上原始對話、產品畫面或私人 review 輸出。
